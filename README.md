# AUREON

## Global News Intelligence

Aureon is an automated global news intelligence platform that collects information from selected sources, clusters related stories, compares information, summarizes verified facts, and presents important events clearly.

### Vision

To make the world's important information understandable, fast, transparent, and accessible.

### Core Principles

- Source-first
- Multi-source verification
- Fast updates
- Transparent sourcing
- Original summaries
- Automated processing
- Human-centered information
